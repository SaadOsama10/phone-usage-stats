About the dataset

Mobile Device Usage and User Behavior Dataset by Vala Khorasani (Kaggle): 700 smartphone users with device model, OS, app usage, screen-on time, battery drain, apps installed, data usage, age, gender and a usage class. Used unmodified under the Apache License 2.0 (licence text). Its author notes it is not a reliable source for papers, so treat results as a statistics exercise, not findings about real users.

Every statistic comes from stats_tools.py, written by hand with only Python's math module (no pandas, NumPy or SciPy), executed unchanged in your browser via Pyodide. The charts only draw numbers computed by that Python code.
